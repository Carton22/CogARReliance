# Cue Text and Challenge Audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Update the Shelf assembly and Boba tea cue text and audio, add one missing Boba recovery cue, and make the Challenge button play a distinct "I think it's appropriate to …" clip in the Training, Shelf, and Boba plans.

**Architecture:** All cue text lives in plain string arrays near the top of `app/page.tsx`, and audio paths are either derived from a folder/prefix convention or declared in per-plan override maps. Challenge audio is derived, not hand-mapped: a helper rewrites a cue's audio path to `<basename>_challenge.mp3` and its text to the prefixed sentence, and `correctTasks()` attaches the result as `challengeOptions` when a per-plan flag is set. The Challenge button falls back to `correctOptions[0]` when no challenge clip is declared, so Sandwich and Table keep today's behavior with no branching.

**Tech Stack:** Next.js 16, React 19, TypeScript, Node.js built-in test runner (`node --test`), static MP3 assets under `public/audio/`.

## Global Constraints

- All new audio files are `.mp3`. No new `.wav` files.
- Every clip is generated with: model `gpt-4o-mini-tts`, voice Nova, speed 1.00x, format MP3, instructions `Speak in professional way for a presentation in academic paper and user study`.
- Challenge sentence rule: `"I think it's appropriate to "` + cue text with its first character lowercased + `"."`
- Challenge path rule: the cue's `audioSrc` with its `.mp3`/`.wav` extension replaced by `_challenge.mp3`.
- Challenge audio applies to the Training, Shelf assembly, and Boba tea plans only. Sandwich and Table assembly are untouched.
- `shelfCorrectSteps[1]` ("Insert a green at slot 1 of the yellow") stays as-is by explicit decision.
- Fast iteration uses `npm run test:unit`. `npm test` additionally runs the build and is the final gate.
- Source of truth for phrases and filenames: `docs/superpowers/specs/2026-08-13-tts-phrases.txt`.

- [ ] **Step 4: Extend `correctTasks` with the challenge flag**

Replace `correctTasks` with:

```ts
function correctTasks(
  steps: string[],
  audioFolder: string,
  audioPrefix: string,
  audioOverrides: AudioOverrides = {},
  withChallenge = false,
): Task[] {
  return steps.map((text, index) => {
    const option = {
      text,
      audioSrc:
        audioOverrides[index] ??
        `/audio/${audioFolder}/${audioPrefix}_${String(index + 1).padStart(2, "0")}.mp3`,
    };

    return {
      name: text,
      correctOptions: [option],
      ...(withChallenge ? { challengeOptions: [toChallengeOption(option)] } : {}),
      mainKind: "correct" as const,
    };
  });
}
```
